# CB Code CRM

Team app for Basel Algamal's sales team: https://baselalgamal88-wq.github.io/cb-code-crm/

No client data is stored in this repository. Data lives in Firebase (project cb-code-crm) and each person can read only their own data (see firestore.rules). The `data` branch holds an encrypted transfer file that only Basel's sync can open.
